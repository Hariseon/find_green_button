# Green Button Finder

Поиск и нажатие зелёной кнопки в Android-приложении через `adb` и OpenCV.

## Что делает

1. Запускает приложение по package name на подключённом телефоне.
2. Снимает экран и ищет на нём зелёную кнопку.
3. Нажимает на найденную кнопку.
4. Если кнопки нет — сообщает об этом.

Таймаут поиска — 10 секунд.

## Требования

- Python 3.12+
- `adb` в `PATH`
- Подключённый по USB телефон с включённой отладкой

## Основная логика работы

1. После получения скриншота производится поиск всех объектов на экране через Canny и простым поиском по зеленому, чтобы отловить то, что потерял Canny.
2. Далее производится кластеризация найденных элементов, чтобы понимать с чем производится работа. Часто встречаемые одинаковые элементы - визуальный шум
3. После происходит назначение score, значения соответствия объекта слову "кнопка".
4. Производится сравнение score:
  4а. если порог не пройден - не нажимаем;
  4б. близкие по score элементы - вывод информации об них;
  4в. score прошёл порог, и кандидат один - нажимаем на кнопку.

## Структура репозитория

1. find_green_button.py - главный файл
2. adb.py - методы для работы с Android
3. analysis.py - методы для кластеризации и отбора объектов
4. config.py - файл с переменными
5. cv_vision.py - методы для работы с cv2 и поиском объектов на скриншоте
6. debug.py - файл для сохранения визуальных итогов поиска
7. models.py - файл с dataclass используемых в проекте
8. orphans.py - дополнительные методы для поиска потерянных объектов из-за близкого с фоном цвета

## Функциональные флаги

- `--debug` - включает сохранение картинок с ходом работы. Можно посмотреть что вообще детектилось и как отсеялось. Окрашивание рамок описано в debug.py
- `--timeout N` - изменяет таймаут, default = 10

## Пример запуска

```bash
python find_green_button.py com.sh.smart.caller --debug
```
